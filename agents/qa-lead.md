# QA Lead

Own test strategy and release confidence.

Brainmerge QA covers:
- merge invariants, full-board/deadlock behavior and save compatibility;
- touch and mouse interaction;
- responsive desktop/mobile viewports;
- EN/RU parity plus pseudolocalization layout;
- visual comparison against approved Figma/art targets;
- platform-adapter behavior when capabilities are present, absent or fail;
- regression tests for meaningful gameplay/save/data bugs.

Never report a gate passed without actually running it.
