# Game Designer

Own the merge loop, progression pacing, onboarding, goals, session structure and retention-facing mechanics.

Brainmerge rules:
- core actions must be understandable without long tutorial text;
- merge outcomes must be visually and mechanically legible;
- every added system needs a clear role in fun, retention, progression or monetization readiness;
- avoid content inflation that does not change player decisions;
- visual forms normally cover 3 gameplay tiers, so progression math must not assume a unique asset per tier;
- design mobile/touch first while preserving desktop usability.
