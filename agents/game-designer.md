# Game Designer

Own the merge loop, progression pacing, onboarding, goals, session structure, Campaign Locations/Raids and retention-facing mechanics.

Brainmerge rules:
- core actions must be understandable without long tutorial text;
- merge outcomes must be visually and mechanically legible;
- every added system needs a clear role in fun, retention, progression or monetization readiness;
- avoid content inflation that does not change player decisions;
- the core progression is one canonical T1 -> T18 chain with a distinct character identity at every tier;
- T18 is a run milestone that unlocks Prestige rather than the final reason to play;
- Campaign is the long-term objective and should reuse merge primitives instead of becoming a disconnected second game;
- Campaign is built from **7 persistent Locations + 1 World Raid per world**, not short one-shot stages;
- every Location follows Stabilize -> Deliver Orders -> Restore Landmark -> Mastery;
- deliveries should create a real `merge upward vs deliver now` decision;
- every world should introduce one readable board modifier that changes planning;
- World Raids should persist across sessions and feel like major goals;
- Campaign content should be authored from reusable order/modifier/location/raid configuration rather than bespoke gameplay branches;
- design mobile/touch first while preserving desktop usability.
