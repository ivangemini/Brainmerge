# Studio framework provenance

Brainmerge's agent/skill/rule structure is adapted for this project from `ivangemini/Brainrot`.

That repository states it was bootstrapped from Donchitos/Claude-Code-Game-Studios v1.0.0 under the MIT License and adapted to a single Codex/ChatGPT operating model.

Brainmerge intentionally does not import engine-specific Godot/Unity/Unreal role profiles or generic rules that conflict with approved Brainmerge project decisions. Root `AGENTS.md` defines the active precedence.
