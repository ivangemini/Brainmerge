# Brainmerge

Brainrot-themed merge game for Yandex Games.

## Art workflow

- Approved generated character references live in `art/approved/tier-1/`.
- `docs/ASSET_MANIFEST.md` is the canonical asset index.
- `docs/ART_BIBLE.md` defines the locked visual direction.
- Runtime-ready assets will be derived from approved references after background cleanup/cropping/optimization.
