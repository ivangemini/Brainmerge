# Visual Quality Rules

- `docs/ART_BIBLE.md` and approved Figma frames are authoritative.
- Character assets must remain readable at actual merge-cell size.
- Runtime presentation should use approved art/derived production assets, not generic placeholder SVGs when claiming production readiness.
- Compare player-facing runtime screenshots to the approved target during visual QA.
- Preserve consistent material, lighting, palette and silhouette language across generated assets.
- Board/gameplay state FX must not obscure character identity or interaction targets.
